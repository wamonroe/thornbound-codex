# The Thornbound Codex

## About

The Thornbound Codex is a community-maintained reference built from the Creative Commons–licensed
text of Grimwild, a cinematic fantasy tabletop roleplaying game using the Moxie system by J.D.
Maxwell and Oddity Press.

This project is fan-supported, non-official, and designed to grow alongside its community. All
included text is licensed under CC BY 4.0, making it free to reuse—personally or commercially—for
adventures, rules supplements, or entirely new games.

## Developer Setup

This project uses [Devbox](https://www.jetpack.io/devbox/) for local development and
[Vite](https://vitejs.dev/) for the React/TypeScript app.

### Getting Started

1. **Clone the repository:**

   ```sh
   git clone https://github.com/wamonroe/thornbound-codex.git
   cd thornbound-codex
   ```

2. **Install Devbox (if you don’t have it):**
   See [Devbox installation instructions](https://www.jetify.com/docs/devbox/installing_devbox/).

3. **Start your Devbox shell:**

   ```sh
   devbox shell
   ```

4. **Install dependencies:**

   ```sh
   npm install
   ```

5. **Start the development server:**

   ```sh
   npm run dev
   ```

6. **Open [http://localhost:5173](http://localhost:5173) in your browser.**
